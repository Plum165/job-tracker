# Assets Directory

This directory contains static visual assets, icons, logos, and placeholders used across the application.

## Contents

- `logo.png` / `logo.svg`: Primary application logo placeholder.
- `favicon.png`: Browser tab icon placeholder.
- `images/`: Static graphic assets, company badges, and illustrations.
- `icons/`: SVG icon vectors used for application branding.

## Guidelines

1. SVG format is preferred for scalable icons and logos.
2. Store raster image assets optimized for web performance.
3. Keep filenames lowercase with hyphen separators (e.g. `company-avatar-placeholder.png`).
