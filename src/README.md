# Source Code Directory

Contains all application source files, components, data stores, utility helpers, and state management.

## Directory Overview

- `frontend/`: User interface components, views, hooks, styles, and interactive state modules.
- `backend/`: Client-side virtual backend API layer, IndexedDB storage engine, and JSON data catalog handlers.
- `types/`: Shared TypeScript data structures and interfaces.
- `lib/`: IndexedDB storage drivers, Excel parsers, date calculators, and event bus utilities.
- `data/`: Curated shared catalog of company job opportunities.
