# Frontend Component & UI Layer

This folder houses the React 19 visual interface, views, modular components, theme contexts, and responsive layouts.

## Architecture

- `components/`: Modular UI widgets (Kanban Board, List Views, Detail Modals, Calendar, Contacts CRM, Excel Import Wizard, Data Manager).
- `context/`: React Context providers for global theme, workspace filter state, and active toast notifications.
- `hooks/`: Custom hooks for IndexedDB queries, search filtering, and responsive container resizing.
